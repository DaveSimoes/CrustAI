## 🚀 What is CrustAI?

CrustAI is an AI Assistant built with JavaScript that allows you to run an intelligent assistant locally, integrate with external services, enable voice interaction, and access it remotely — all while keeping control over your environment.

This documentation will guide you through setup, architecture, integrations, and advanced features.

## 🧠 Architecture Overview

CrustAI was designed with a modular architecture that makes it easy to expand, customize, and integrate new capabilities without breaking the core system.

You can explore more in the dedicated sections of this documentation.

---

## 💡 Why CrustAI?

Most AI assistants today depend heavily on cloud infrastructure and external platforms.  
CrustAI focuses on:

- Local-first execution
- Privacy and control
- JavaScript ecosystem flexibility
- Extensibility through integrations
- Voice and remote capabilities
